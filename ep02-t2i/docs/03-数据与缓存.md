# 03 · 数据与缓存:从磁盘到一个 batch

小麻雀训练时**不跑任何冻结零件**:所有图/声音/视频都在训练前由 `encode.py` 过一遍冻结编码器,把向量缓存到磁盘。`sparrow.py` 里的 `Cache` 负责读缓存、归一化、每步取一批。本篇最后有一张 t2i 的完整张量形状追踪表。

## 1. 缓存从哪来:encode.py(简述)

`encode.py --parts img`(本集只编 img)产出:

| 文件 | 键(`份.字段`) | 形状 / 类型 | 说明 |
|---|---|---|---|
| `labels.npz` | `train.img_animal`、`train.img_color`、`test.*`、`train/test.vid_*` | int | 每次都写 |
| | `voice.animal`、`voice.test`、`voice.wav_index` | | 录音标签;本集 `voice.npz` 是空的,这几项长度为 0 |
| `img.npz` | `train.img_lat` | `[60000, 32, 8, 8]` fp16 | FLUX.2 VAE 编码,取后验分布的众数 `latent_dist.mode()`(确定性,不采样) |
| | `test.img_lat` | `[2000, 32, 8, 8]` fp16 | |

其它零件的字段名:`vid.npz` → `vid_lat`,`aud.npz` → `voice.aud_lat`,`see.npz` → `img_see`,`watch.npz` → `vid_see`,`hear.npz` → `voice.aud_hear`。`sparrow.py` 用 `FIELD` 把模态名映射到字段名:

[sparrow.py:208](../code/sparrow.py#L208)

```python
FIELD = {"img": "img_lat", "vid": "vid_lat", "aud": "aud_lat", "see": "img_see", "watch": "vid_see", "hear": "aud_hear"}
```

> **注意 · 为什么本集还要一份空的 voice.npz**:`Cache.__init__` 无论训什么任务都会读 `labels.npz` 里的 `voice.test` 并计算 `self.vtr`([sparrow.py:232](../code/sparrow.py#L232)),`encode.py` 也总会写这几个键。所以 README 第 ② 步要先放一份空录音文件。

## 2. 形状变换:`tokens` / `untokens`

[sparrow.py:187-205](../code/sparrow.py#L187)

主干要的是「一串向量」`[N, 向量个数, 维度]`,缓存里存的是零件的原始形状。`tokens` 负责摊平,`untokens` 负责还原回冻结解码器要的形状:

| 字段 | 缓存原始形状 | `tokens` 之后 | 怎么排 |
|---|---|---|---|
| `img_lat` | `[N, 32, 8, 8]` | `[N, 64, 32]` | `flatten(2).transpose(1, 2)`:8×8 格子按行优先排成 64 个,每格 32 个通道 |
| `vid_lat` | `[N, 16, 5, 8, 8]` | `[N, 320, 16]` | `permute(0,2,3,4,1)`:**按帧排**,先第 0 帧的 64 格,再第 1 帧……与 `embed` 里 `where.repeat` / `when.repeat_interleave` 对应 |
| `aud_lat` | `[N, 26, 512]` | `[N, 104, 128]` | 每个 Mimi 帧切成 4 段(`aud_split=4`) |
| 理解特征 | `[N, n, d]` | 不变 | 已经是向量序列 |

## 3. 归一化:`norm` / `denorm`

[sparrow.py:211-218](../code/sparrow.py#L211)

```python
def norm(stat, mod, x):
    return (tokens(FIELD[mod], x.float()) - stat[mod][0]) / stat[mod][1]

def denorm(stat, mod, x):
    return untokens(FIELD[mod], x.float() * stat[mod][1] + stat[mod][0])
```

`stat[mod] = [mean, std]`,形状都是 `[维度]`——**按通道**统计(img 是 32 个通道各一组),同一通道在 64 个格子位置上共用一组均值方差。

为什么要归一化?流匹配把数据 `x1` 和标准正态噪声 `ε` 连成直线(见 [04](04-训练方式.md))。如果 `x1` 的尺度和 `ε` 差很多,直线的「一头大一头小」,不同 t 下的学习难度就很不均衡。逐通道标准化到「均值 0、方差 1」,数据端和噪声端尺度一致。

`denorm` 是生成完之后用的:把模型画出的归一化向量还原成 VAE 解码器认识的原始潜变量 `[B, 32, 8, 8]`。统计量会存进 `final.pt` 的 `stat`,所以 `infer.py` 不需要缓存也能还原。

## 4. `Cache`:读缓存、算统计量、取一批

[sparrow.py:221-250](../code/sparrow.py#L221)

### 初始化

```python
for f in ["labels", *sorted(mods)]:
    for k, v in np.load(f"{path}/{f}.npz").items():
        s, name = k.split(".", 1)
        split[s][name] = torch.from_numpy(v).to(dev if f == "labels" else "cpu")
```

- **标签放显卡,向量留内存**。每步只把这一批向量搬上卡,所以显存只跟批大小和任务有关,跟缓存多大无关(本集训练峰值 4.51 GB)。
- 只读 `mods`(= `needs(tasks + eval_tasks)`)用到的那几份;本集只读 `labels.npz` 和 `img.npz`。

然后为每种向量算统计量:

```python
src = self.voice[field][vtr.cpu()] if field.startswith("aud") else self.tr[field]
n, s1, s2 = 0, 0, 0
for c in src.split(512):
    x = tokens(field, c.double()).flatten(0, 1)
    n, s1, s2 = n + len(x), s1 + x.sum(0), s2 + (x * x).sum(0)
mean = s1 / n
st = {mod: [mean.float(), ((s2 - n * mean * mean) / (n - 1)).sqrt().float() + 1e-4]}
```

- 只用**训练集**(声音类只用训练录音)算统计量,测试集用同一组归一化,不泄漏测试信息。
- 按 512 条一块、用 **float64** 累加一阶矩和二阶矩,再用 `Var = (Σx² − n·mean²)/(n−1)` 求无偏方差。缓存是 fp16,6 万张 × 64 格的平方和直接用低精度累加会溢出或丢精度,所以分块转 double。
- `std + 1e-4` 防止某个通道几乎恒定时除以 0。

算完后把训练集、测试集、录音里的这个字段**原地替换**成归一化后的 fp16 `[N, 向量个数, 维度]`,之后取数据就不用再算。

最后为 a2i 准备「按动物分组」的索引:

```python
by = [torch.nonzero(self.tr["img_animal"] == k).squeeze(1) for k in range(len(ANIMALS))]
self.count = torch.tensor([len(b) for b in by], device=dev)
self.by_animal = torch.stack([F.pad(b, (0, int(self.count.max()) - len(b))) for b in by])
```

`by_animal[a]` 是第 a 种动物所有训练图的下标(用 0 补齐成同样长度),`count[a]` 是真实个数。采样时下标 `< count[a]`,所以补的 0 永远不会被取到。

### 取一批:`get(task, B)`

[sparrow.py:255-274](../code/sparrow.py#L255)

返回 `(词槽, 各段向量)`:词槽是 `{"C": [B], "A": [B], "T": [B]}` 的词 id;各段向量按模板里元组的顺序排列,已搬上卡。

| 任务 | 从哪取 | 词槽 | 向量 |
|---|---|---|---|
| t2i / i2t | 训练图,随机下标 `i` | 颜色、动物 | t2i: `img_lat[i]`;i2t: `img_see[i]` |
| t2v / v2t | 训练动画 | 颜色、动物、动作 | t2v: `vid_lat`;v2t: `vid_see` |
| t2a / a2t | 训练录音(`vtr`) | 动物 | t2a: `aud_lat`;a2t: `aud_hear` |
| a2i | 训练录音 + **同种动物随便一张图** | 无 | `[aud_hear[i], img_lat[j]]` |

```python
if task in ("t2i", "i2t"):
    i = r(len(tr["img_animal"]))
    return ({"C": COLOR_ID.to(dev)[tr["img_color"][i]], "A": ANIMAL_ID.to(dev)[tr["img_animal"][i]]},
            [pick(tr[FIELD["img" if task == "t2i" else "see"]], i)])
```

`img_color` 存的是颜色**类别号**(0–7),`COLOR_ID` 把它映射成**词表 id**,才能填进序列。

> **注意 · 有放回随机采样,没有 epoch 概念**:每步用 `torch.randint` 独立抽 512 个下标。本集 4000 轮 × 512 = 204.8 万次采样,相当于把 6 万张训练图平均看了约 34 遍,但不保证每张恰好看到同样次数。

> **注意 · a2i 的图和录音没有一一对应**:录音只说了动物名(没说颜色),所以每条录音随机配一张**同种动物、任意颜色**的训练图。模型学到的是「听到小猫 → 画某种颜色的小猫」,颜色由起点噪声决定。

> **注意 · `pick` 先把下标搬回 CPU**:`pick = lambda x, i: x[i.cpu()].to(dev)`。向量在 CPU 内存里,下标在卡上,所以每步有一次 GPU→CPU 的小同步和一次 CPU→GPU 的拷贝(t2i 每步约 512×64×32×2 字节 ≈ 2 MB)。

## 5. t2i 张量形状追踪表

以本集的配置(`bs=512`,`dim=384`,`heads=6`)跟一个 batch 从磁盘走到 loss:

| # | 位置 | 张量 | 形状 | 类型 / 设备 |
|---|---|---|---|---|
| 1 | `img.npz` | `train.img_lat` | `[60000, 32, 8, 8]` | fp16,磁盘 |
| 2 | `Cache.__init__` → `tokens` | 摊平 | `[60000, 64, 32]` | |
| 3 | `Cache.__init__` → `norm` | 逐通道归一化后原地替换 | `[60000, 64, 32]` | fp16,CPU |
| 4 | `Cache.get` | 下标 `i` | `[512]` | int64,cuda |
| 5 | | 词槽 `C`、`A` | `[512]` 各一 | 词表 id |
| 6 | | `segs[0]` = `img_lat[i]` | `[512, 64, 32]` | fp16 → `train` 里转 float |
| 7 | `train` | `t = sigmoid(randn)` | `[512]` | float |
| 8 | | `eps` | `[512, 64, 32]` | 标准正态 |
| 9 | | `z_t = (1−t)·eps + t·x1`(替换 `segs[-1]`) | `[512, 64, 32]` | |
| 10 | | `drop`(10% 为 True) | `[512]` | bool |
| 11 | `fill_tok` | `tok` | `[512, 68]` | 只有 0–3 位有意义 |
| 12 | `forward` 文字段 | `self.tok(tok[:, 0:4])` | `[512, 4, 384]` | 以下在 bf16 autocast 内 |
| 13 | `embed` | `inp.img(z_t)` | `[512, 64, 384]` | |
| 14 | | `+ where.img` | `[64, 384]` 广播 | |
| 15 | | `sinus(t)` → `temb` → `[:, None]` | `[512, 256]` → `[512, 1, 384]` | 广播到 64 位 |
| 16 | `forward` | `cat + pos.weight[:68]` | `[512, 68, 384]` | |
| 17 | `Block` | `qkv(n1(x))` → view → permute | `[512, 68, 1152]` → `[3, 512, 6, 68, 64]` | |
| 18 | | `scaled_dot_product_attention(…, attn_mask=[68, 68])` | `[512, 6, 68, 64]` → `[512, 68, 384]` | |
| 19 | | MLP 隐层 | `[512, 68, 1536]` | |
| 20 | 8 层后 `norm` | `h` | `[512, 68, 384]` | |
| 21 | `flow_head.img(h[:, 4:68])` | 速度 `v` | `[512, 64, 32]` | |
| 22 | `text_head(h)` | logits(t2i 不用) | `[512, 68, 27]` | |
| 23 | `train` | `F.mse_loss(v.float(), x1 − eps)` | 标量 | float32 |

生成时(见 [05](05-生成理解与评测.md))的出口方向:

| 步 | 张量 | 形状 |
|---|---|---|
| `generate` 输出 | 归一化潜变量 `x` | `[B, 64, 32]` |
| `denorm` | `x·std + mean` → `untokens` | `[B, 32, 8, 8]` |
| `frozen.ImageVAE.decode` | uint8 图 | `[B, 64, 64, 3]` |
