## 1. `evaluate` 的总体变化

[sparrow.py:794-978](../code/sparrow.py#L794)

| 方面 | 第 2 集 | 第 4 集 |

## 2. t2i:分组合正确率 + 新的最近邻口径

### 2.1 `both_by_combo`

[sparrow.py:839-848](../code/sparrow.py#L839)

```python
ok = (pa == ai) & (pc == ci)
rep["t2i"] = {..., "both_acc": acc(ok),
              "both_by_combo": [[acc(ok[(ai == an) & (ci == c)]) for c in range(8)] for an in range(6)]}  # 行=动物、列=颜色,各 8 张
```

384 张图 = 6 种动物 × 8 种颜色 × 8 张。第 4 集多报一个 6×8 的表,能看出是哪个「颜色 × 动物」组合掉了分。4-2 里只练念名字的 `replay_0` 画图掉到 0.8%,用这张表可以看清遗忘是不是均匀发生的。

### 2.2 最近邻:「有没有背训练图」

第 2 集的做法:取前 128 张生成图和前 128 张测试图,各自算到训练集的最近欧氏距离,只报平均值(`nn_dist_gen_mean` / `nn_dist_test_mean`)。

第 4 集拆成了几个函数([sparrow.py:668-715](../code/sparrow.py#L668)):

| 函数 | 作用 |
|---|---|
| `topk_rmse(q, base, k)` | `q` 里每张图到 `base` 里最像的 k 张的距离和序号。距离 = 整图 L2 / √12288,即**每个像素通道的均方根误差(0~255)**。`base` 留在内存里,每次搬 8192 张上卡 |
| `rmse_to(q, base)` | k=1 的简写 |
| `paired_test(raw_te, animal, color)` | 给每张生成图配一张**同颜色同动物**的独立测试图,作为基准 |
| `nearest(gen, animal, color, train_u8, raw_te, ex, tag)` | 生成图和配对测试图各自到训练集的最近距离:报分位数(0/5/25/50/75/95/100)和**中位数之比**;另存最像训练图的 8 张生成图并排对照图 `nearest_<tag>.png`,以及每张图的距离 `nearest_<tag>.csv` |

几处改进:

- **全部 384 张**都比较,不再只取 128 张。
- **基准按组合配对**:生成图是什么颜色和动物,测试基准就用同样的颜色和动物,不会因为组合分布不同而有偏差。
- **只搜这次实际用的训练图**(`data.img`,详见 06 的 `--per_combo/--hold`)。
- 主要读数是 `median_ratio_gen_over_test`:生成图到训练集的中位距离 ÷ 测试图到训练集的中位距离。接近 1,说明生成图离训练集的远近和一张新的真图差不多;远小于 1,才需要怀疑是在背训练图。

对照 report.json 里的数字:

| 权重 | 生成图中位距离 | 测试图中位距离 | 比值 |
|---|---:|---:|---:|
| `replay_512`(画图 100%) | 22.57 | 19.94 | 1.13 |
| `replay_0`(画图 0.8%) | 34.25 | 19.94 | 1.72 |

画图忘掉以后,生成的图离训练集也更远了,说明它画出来的已经不像这个小世界里的东西。

## 4. `infer.py` 的新能力

[infer.py](../code/infer.py)(85 → 165 行)。文件开头的说明里写了一条总原则:**用哪个零件、视频取哪几帧、视频怎么解码,都按这份权重训练时的配置来。**

### 4.1 新参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `--seed N` | 0 | 起点噪声的种子,用 `S.start_noise(lay, 1, N)` 生成 |
| `--noise 文件.pt` | — | 直接使用存好的起点噪声(形状 `[1, 向量数, 维度]`),给了就不看 `--seed` |
| `--cfg` | 3.0 | 引导强度 |
| `--steps` | 30 | 采样步数 |
| `--stat_from 另一份.pt` | — | 这份权重缺某种向量的归一化统计量时,从另一份权重**只补缺的那几种**,来源记进 `--record` |
| `--nearest K` + `--data D` | 0 | t2i / a2i:再找出这份权重训练时实际用过的训练图里最像的 K 张,存为 `<输出>_nn<k>.png` |
| `--record 文件` | — | 每次调用往这个文件追加一行 JSON:权重哈希、输入、噪声(种子或张量哈希)、CFG、步数、回答或输出、近邻 |

另外:

- 每次生成都会存一份起点噪声 `<输出>.noise.pt`。下次用 `--noise` 传回去,就能复现同一个结果。
- 生成视频时,除了 gif,还另存 `<输出>_frames/frame_00..15.png` 和 `frames.npy`,可以原样喂回 `v2t`。

### 4.2 统计量缺失:报错而不是将就

```python
mods = [x[0] for x in S.TEMPLATES[a.task] if isinstance(x, tuple)]
...
missing = [m for m in mods if m not in stat]
if missing:
    raise SystemExit(f"这份权重没有 {missing} 的归一化统计量(那一集没训也没评这样本事);要用就加 --stat_from 另一份权重")
```

第 2 集遇到这种情况会在 `S.norm` 里直接 KeyError。例如拿第 2 集的权重去念名字:它的 `stat` 里只有 `img`,没有 `aud`,现在会给出明确的提示。

### 4.3 输入读得更准

- [`to64`](../code/infer.py#L32):图片边长正好是 64 的整数倍(本仓库导出的放大图都是 256×256)时,按**最近邻**缩回 64×64,逐像素还原;其他图片才用双线性。第 2 集一律用双线性,导出的图再读回来就有偏差。
- [`movie`](../code/infer.py#L43):视频输入支持 `.gif`、16 帧的 `.npy`,或者放了 16 张 png 的目录;帧数不是 16 就报错。第 2 集只读 gif,帧数不够 16 也不会提示。
- `v2t` 取帧时按权重里的 `watch_frames` 设定(用 `S.watch_index` 计算);`i2t` 遇到用 `--see_from img` 训练的权重,改用 FLUX.2 潜变量(见 06)。

### 4.4 例子

```bash
cd ep04-t2a/code
# 念名字,换一团起点噪声,并记录这次调用
python infer.py ../weights/course_ep4/final.pt t2a 小狗 ../work/dog.wav --seed 1 --record ../work/calls.jsonl
# 用上次存下的噪声复现
python infer.py ../weights/course_ep4/final.pt t2a 小狗 ../work/dog2.wav --noise ../work/dog.wav.noise.pt
# 画图并找出最像的 3 张训练图(需要 world_train.npz)
python infer.py ../weights/replay_512/final.pt t2i '蓝色 小狗' ../work/dog.png --nearest 3 --data ../work/data
```
