# 06 · 本集未用到的开关

第 4 集的 `sparrow.py` 里还有一批参数,第 4 集的 README 和 EXPERIMENTS 里**一条命令都没用到**。它们是给其他集的对照实验准备的(从代码注释看,涉及记忆还是泛化、视频表示、看图编码器、音色多少、听→画有没有真的在听等问题)。默认值都等于「不启用」,所以不影响本集的结果。

本篇每节都标〔本集未使用〕,只讲它们做什么、怎么实现,读代码时碰到能认出来。

| 参数 | 一句话 | 关键函数 |
|---|---|---|
| `--per_combo K` | 每个「颜色 × 动物」组合只用前 K 张训练图 | `pick_images` |
| `--hold red-rabbit,...` | 训练时去掉这些组合,评测时专门考它们 | `pick_images`、`combos` |
| `--match_total` | 和 `--hold` 配合:那些组合照常保留,改为随机去掉同样多张(对照组) | `pick_images` |
| `--see_from img` | 看图改用 FLUX.2 潜变量,而不是 SigLIP2 | `configure`、`seelat` |
| `--vid_lat vidimg` | 生成视频改用逐帧 FLUX.2 潜变量,而不是 Wan 时空潜变量 | `configure`、`vidimg` |
| `--watch_frames n` | 看视频时 16 帧里只取 n 帧 | `watch_index` |
| `--voices n --voice_draw d --clips c` | 训练录音只用 n 个音色、共 c 条 | `pick_voices` |
| `--a2i_shuffle` | 听→画评测时,另把录音换成别种动物的再考一遍 | `mismatch_perm` |
| (t2v 评测) | 视频的两把尺子 + 判卷器自检 | `video_rulers`、`video_calibration` |

这些参数都在 `DEFAULTS` 里(除了 `--a2i_shuffle`),所以会随权重一起保存;`load`、`--init`、`--eval_only` 时按权重里的值还原(见 [02](02-接续训练与旧题回放.md))。

## 1. 训练图子集:`--per_combo` / `--hold` / `--match_total`〔本集未使用〕

[sparrow.py:98-120](../code/sparrow.py#L98)

```python
def pick_images(color, animal, per_combo=0, hold="", match_total=False):
    keep = np.ones(len(color), bool)
    combo = color * len(ANIMALS) + animal
    if per_combo:                                   # 每个组合只留前 K 张(按原顺序)
        ...
        keep &= rank < per_combo
    if hold:
        held = np.isin(combo, [c * len(ANIMALS) + an for c, an in combos(hold)]) & keep
        if match_total:                             # 对照组:那些组合照留,随机去掉同样多张(随机数固定为 0)
            keep[np.random.default_rng(0).choice(np.nonzero(keep)[0], held.sum(), replace=False)] = False
        else:
            keep &= ~held                           # 实验组:那些组合一张不留
    return np.nonzero(keep)[0]
```

- 返回的是训练图的**序号**,存在 `Cache.img` 里。`Cache.get` 只从这些序号里抽,统计量也只按这些图计算([sparrow.py:390-394](../code/sparrow.py#L390))。
- 实验组和对照组的训练图张数相同,区别只在于缺的是不是那几个组合。这样比较时,「组合没见过」和「训练图变少」两个因素被分开了。
- **评测**([sparrow.py:855-872](../code/sparrow.py#L855)):`--hold` 的每个组合另外生成 40 张(起点噪声编号从 1000 开始,不和网格题重复),报告 `hold.both_acc`、`by_combo`、`seen_grid`(网格里见过的那些组合的成绩),以及只针对这些组合的最近邻 `nearest_hold`。
- 最近邻和 `infer.py --nearest` 都只在这个子集里搜索(`data.img`、`S.pick_images`)。
- 子集的描述写进 report 的 `train_subset.images`。

## 2. 看图换编码器:`--see_from img`〔本集未使用〕

[sparrow.py:80-87](../code/sparrow.py#L80)

```python
if a["see_from"] == "img":
    MODS["seelat"] = (32, 64, 1, False)            # 64 个 32 维,不加噪(理解用)
    TEMPLATES["i2t"] = ["<bos>", "<img>", ("seelat", False), "</img>", "C*", "A*", "<eos>*"]
```

默认的看图(i2t)用的是 SigLIP2 的 16 个 768 维特征。打开这个开关后,看图改用**生成那一侧的** FLUX.2 潜变量,同样经过两层的 LLaVA 式投影进入主干。比较的是:理解和生成能不能共用同一套编码器。

配套改动:

- `FIELD["seelat"] = "img_lat"`、`FILE["seelat"] = "img"`:直接读生图那份缓存,不用重新编码。
- `img` 和 `seelat` 读同一个字段,但统计量可能不同,这就是 `Cache` 里「统计量相同才共用,不同就各存一份 `img_lat@seelat`」那段逻辑的来源(见 [02 第 2.3 节](02-接续训练与旧题回放.md#23-同一份缓存不同统计量))。
- `--init` 时允许缺 `inp.seelat`、`where.seelat`(上一集没有这个模态,新建初始化),记进 `init_fresh_params`。
- `infer.py i2t` 遇到这种权重,改用 `frozen.ImageVAE().encode`([infer.py:106](../code/infer.py#L106))。

## 3. 视频换表示:`--vid_lat vidimg`〔本集未使用〕

[sparrow.py:88-90](../code/sparrow.py#L88)

```python
if a["vid_lat"] == "vidimg":
    MODS["vidimg"] = (32, 64, 16, True)            # 16 帧 × 64 个 32 维 = 1024 个向量
    TEMPLATES["t2v"] = ["<bos>", "C", "A", "T", "<vid>", ("vidimg", True)]
```

默认的 t2v 用 Wan2.1 视频 VAE 的时空潜变量(5 帧 × 64 个 16 维,时间也压缩了)。`vidimg` 则是**逐帧**过图像 VAE(FLUX.2),时间上不压缩。用来比较「压时间」和「不压时间」两种视频表示。

配套改动:

- `encode.py` 新增零件 `vidimg`(不在默认的 `--parts` 里):逐帧编码成 `[N, 16, 32, 8, 8]`,同时测「编码再解码」后判卷器的准确率。
- `tokens` / `untokens` 新增 `vid_img` 分支:`[N, 16, 32, 8, 8] ↔ [N, 1024, 32]`,按帧排列。
- `evaluate` 里 `vmod = lays["t2v"].noisy[0]`,`videos(z)` 按 `vmod` 选择 Wan 解码或逐帧 FLUX.2 解码。
- `infer.py` 生成视频时,如果 `mod == "vidimg"`,就把每一帧各自解码([infer.py:128](../code/infer.py#L128))。
- 序列长度会变成约 1029,超过默认的 `maxlen=400`。因此 `main` 会检查 `序列长度 > --maxlen` 就退出([sparrow.py:1107-1109](../code/sparrow.py#L1107)),这时要同时设大 `--maxlen`;两版对照时还要写成同一个值,公共主干的 `pos` 形状才相同。

## 4. 看视频只取几帧:`--watch_frames n`〔本集未使用〕

[sparrow.py:93-95](../code/sparrow.py#L93)

```python
def watch_index(n):
    """看视频取哪几帧:16 帧均分成 n 段,各取段中点那一帧(n=1 取第 8 帧,n=16 全取)。"""
    return [(2 * k + 1) * 16 // (2 * n) for k in range(n)]
```

- `configure` 设置 `MODS["watch"] = (768, 4, n, False)`,v2t 的序列随之变短。
- `Cache` 把缓存里的 `vid_see` 从 16 帧裁成这 n 帧([sparrow.py:384-389](../code/sparrow.py#L384))。
- `infer.py v2t` 按权重里存的 `watch_frames` 取帧,保证推理和训练一致。
- 用来回答:看视频说出动作,到底需要看几帧?

## 6. 听→画有没有真在听:`--a2i_shuffle`〔本集未使用〕

a2i(听到名字画出来)只判动物。正确率高,可能是真听懂了,也可能是靠别的线索蒙对的。这个开关做的对照是:**同一个模型、同样的起点噪声、标签不变,只把放给它听的录音换成另一种动物的。**

[sparrow.py:760-791](../code/sparrow.py#L760) `mismatch_perm`:

- 优先「按音色整组错排」:同一个音色内部,把各动物的录音按一个**没有动物换回自己**的随机排列对调。这样音色的分布不变,只换了内容。
- 做不到时(某个音色里各动物条数不同),就全局随机打乱,再把仍是同种动物的位置两两换开。
- 最后断言每道题放的都是别种动物的录音。

评测([sparrow.py:961-976](../code/sparrow.py#L961))报告两种口径:

| 字段 | 按什么算对 | 真在听的模型应当 |
|---|---|---|
| `vs_question` | 原题的动物 | 接近 0(放的都是别种动物) |
| `vs_played` | 实际放的那条录音的动物 | 和正常录音那组差不多 |

## 7. 视频的两把尺子:`video_rulers` / `video_calibration`〔t2v 评测,本集未跑〕

[sparrow.py:718-757](../code/sparrow.py#L718)。第 2 集的 t2v 评测只交给视频判卷器判动物、颜色、动作;第 4 集的代码另外加了:

- **相邻帧像素变化**:按动作取平均,得到 15 个点的曲线(`adjacent_rmse_by_action`)。用来检查画面到底有没有在动。
- **逐帧一致**:16 帧逐一交给**图判卷器**,全部判成该动物和颜色才算这一段一致(`frame_consistent`),另报逐帧正确率和按帧序号的正确率。
- **判卷器自检**(`video_calibration`):用全部 500 段真动画,以及「压缩器编码再解码」的往返片,拿同样两把尺子再量一遍。如果图判卷器在真动画单帧上的正确率不到 `VALID_FRAME_ACC = 0.97`,逐帧一致率就标为无效(`frame_consistency_valid = False`)。数字照常输出,只是加上这个标记。
- 同时导出第 0 道题的原尺寸逐帧 png 和 `frames.npy`,以及 3 段真动画、3 段往返片的 gif。
