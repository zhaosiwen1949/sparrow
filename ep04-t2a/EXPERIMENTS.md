# 第 4 集对照实验

这些是片中演示的对照，主线训练见 README。以下命令都在 `code/` 执行，沿用 README 的 `W`、`INIT`、已造数据、判卷器和 `img,aud` 缓存；输出使用新目录。每档只跑一个训练种子，不将接近的结果排高低。

## 4-1：两种声音表示

两版同为 104 个向量、从零只练念名字 8000 轮；比较的是两种表示方案，每格维数和入口、出口大小也不同，不能只归因为压缩倍率。

```bash
python ep1_assets.py --data "$W/data" --cache "$W/cache" --judges "$W/judges" \
  --out "$W/runs/audio_latent" --mod aud --space latent --steps 8000 --seed 0 --rng paired
python ep1_assets.py --data "$W/data" --cache "$W/cache" --judges "$W/judges" \
  --out "$W/runs/audio_waveform" --mod aud --space raw --steps 8000 --seed 0 --rng paired
```

| 表示 | 念名字正确率 | 每格维数 | 完整序列长度 | 训练显存峰值 |
|---|---:|---:|---:|---:|
| Mimi 连续潜变量 | 97.9%（235/240） | 128 | 107 | 7.03 GB |
| 直接波形 | 0.0%（0/240） | 480 | 107 | 7.66 GB |

潜变量版逐字全对 96.2%（231/240）。这里不分发两版参数；脚本输出 `summary.json`、`loss.csv` 与样例，不保存可供 `infer.py` 加载的 `final.pt`。

## 4-2、4-3：带多少画图题

两组都接第 2 集参数，每轮念名字 512 条，画图损失权重始终为 1；每轮带 10 道题不等于只花某个百分比的复习力。

```bash
# 0 道旧题：只练念名字，但同时考画图和念名字
python sparrow.py --data "$W/data" --cache "$W/cache" --judges "$W/judges" \
  --out "$W/runs/replay_0" --init "$INIT" --tasks t2a --eval_tasks t2i,t2a \
  --steps 8000 --seed 0 --rng paired --eval_every 1000
# 其余六档，每轮念名字仍为 512 条；每条命令依次执行
for N in 10 26 51 128 256 512; do
  python sparrow.py --data "$W/data" --cache "$W/cache" --judges "$W/judges" \
    --out "$W/runs/replay_$N" --init "$INIT" --tasks t2i,t2a --bs_task "t2i=$N" \
    --steps 8000 --seed 0 --rng paired --eval_every 1000
done
```

| 每轮画图题数／念名字题数 | 画图正确率 | 念名字正确率 |
|---|---:|---:|
| 0 / 512 | 0.8%（3/384） | 97.9%（235/240） |
| 10 / 512 | 100.0%（384/384） | 95.0%（228/240） |
| 26 / 512 | 100.0%（384/384） | 98.8%（237/240） |
| 51 / 512 | 100.0%（384/384） | 97.5%（234/240） |
| 128 / 512 | 100.0%（384/384） | 96.2%（231/240） |
| 256 / 512 | 100.0%（384/384） | 97.1%（233/240） |
| 512 / 512 | 100.0%（384/384） | 98.3%（236/240） |

1000 轮时，0 档画图 2.1%（8/384）、念名字 73.8%（177/240）；512 档念名字 62.1%（149/240）；10 档画图 99.2%（381/384）。两端点参数已附，其他五档按上面的命令训练。

片中还提到早先一次只练声音的运行，画图 2.3%（9/384），附在 `weights/course_ep4_only_t2a/`。它的随机协议为 `legacy`：可将 0 档命令的 `--rng paired` 改为 `--rng legacy`，并使用另一个新输出目录。它与本集 0.8% 那只分开记。
