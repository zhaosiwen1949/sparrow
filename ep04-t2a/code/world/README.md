# 卡通小世界

课程《从零训一个多模态模型》的贯穿数据集:程序画出的小动物,64×64 RGB,附带结构化标签。纯 Python + numpy + PIL,不需要 GPU。

## 用法

```python
import numpy as np
from world import sample, animate

s = sample(np.random.default_rng(0))            # s["image"]: 64x64x3 uint8;animal/color/bg/facing/scale/x/y
a = animate(np.random.default_rng(0), "jump")   # a["frames"]: 16 帧;action ∈ run_left/run_right/jump/turn
```

同一个种子输出逐像素一致。传 `hd=True` 会多返回 256×256 高清图(`hd` / `hd_frames`)。

出样(拼版、高清拼版、4 段 gif,顺带测速和可复现自检):

```bash
python3 world/world.py --out <目录> [--seed 0] [--bench 500]
```

## 画法

形状用单位坐标描述(朝右,脚底 y=80),在 512×512 上画多边形并描深色边,再缩到 256(高清图)和 64(训练图)。超采样后的抗锯齿让 64×64 下的轮廓也清楚。朝左直接水平翻转。

## 组合数量级

| 维度 | 取值 |
|---|---|
| 动物 | 6(猫、狗、兔、鸟、鱼、熊) |
| 颜色 | 8(红、橙、黄、绿、蓝、紫、粉、棕) |
| 背景 | 4(天空、草地、水、纯色);按栖息地限制:鱼只在水里,鸟在天空/草地/纯色,其余在草地/纯色 → 共 12 种「动物×背景」组合 |
| 朝向 | 2 |
| 动作 | 4(仅 `animate`) |

离散标签组合:12 × 8 × 2 = **192 种**(再乘动作是 768 种)。在此之上还有连续变量:大小(0.72–1.0)、位置、姿态相位、云、草、气泡的摆放、纯色底 5 种色调。所以实际画面近似不重复。

## 速度

本机单核约 **9 ms/张**(64×64,含 512 作画与缩放),**1 万张单核约 1.5 分钟**;按 6 核多进程切种子并行,约 20 秒。一段 16 帧动画约 0.15 秒。
