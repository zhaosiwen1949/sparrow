# 05 · 本集未用到的开关:和理解有关的那几个

本集主线只用了 `--init`、`--tasks`、`--steps`、`--seed`、`--rng legacy`、`--vid_attn full`、`--eval_every 0`,其余全是默认值。代码里还有一批和「理解」有关的选项,都是第 2 集或第 4 集写的,本集一条命令都没用到。它们的实现细节在 [ep04 docs/06](../../ep04-t2a/docs/06-本集未用到的开关.md) 里已经讲过;本篇只说**放到第 6 集的理解题上**,它们各自会改变什么、有哪些限制。

本篇每节都标〔本集未使用〕。下面的命令只是示意,本仓库没有对应的实测结果。

| 开关 | 影响哪些理解题 | 能不能接本集权重 `--init` |
|---|---|---|
| `--tasks ...,a2i` | 听→画(理解输入 + 生成输出) | 能:部件都在 |
| `--see_from img` | i2t 改看 FLUX.2 潜变量 | 能:新部件 `seelat` 允许新建初始化 |
| `--watch_frames n` | v2t 只看 n 帧 | **不能**:`when.watch` 形状变了 |
| `--per_combo` / `--hold` / `--match_total` | i2t 的训练图(和 t2i 共用) | 能 |
| `--voices` / `--voice_draw` / `--clips` | a2t 的训练录音(和 t2a、a2i 共用) | 能 |
| `--bs_task`、`--eval_every`、`--rng paired` | 批量、进度曲线、成对对照 | 能 |

## 1. 听→画 `a2i`〔本集未使用〕

第 7 种序列,第 2 集就写好了,至今没有一集训练过它:

```python
"a2i": ["<bos>", "<aud>", ("hear", False), "</aud>", "<img>", ("img", True)],     # sparrow.py:58
```

它把「听」和「画」接在一起:前半段和 a2t 一样是 Whisper 特征,后半段和 t2i 一样是加噪的 FLUX.2 潜变量。它在 `GEN` 里([sparrow.py:49](../code/sparrow.py#L49)),所以训练走流匹配 MSE,不走交叉熵;没有答案格,也不用 `text_head`。

- **训练数据**([sparrow.py:471-473](../code/sparrow.py#L471)):随机抽一条训练录音,再从**同一种动物**的训练图里随机挑一张配对。颜色不受约束,所以它学的是「听到小猫 → 画一只任意颜色的小猫」。
- **生成**([sparrow.py:634](../code/sparrow.py#L634)):CFG 的无条件那一路借用 t2i 的模板(条件词全换成 `<null>`),因为 a2i 自己没有词槽可以去掉。
- **部件全部共用**:`inp.hear`、`where.hear` 和 a2t 共用,`inp.img`、`where.img`、`flow_head.img` 和 t2i 共用,不新增参数。所以可以直接接本集权重继续练。
- **评测**([sparrow.py:947-960](../code/sparrow.py#L947)):对全部测试录音各画一张,交给图判卷器只判动物,报 `animal_acc` 和逐动物的 `by_animal`。
- **`--a2i_shuffle`**([sparrow.py:961-977](../code/sparrow.py#L961)):另做一遍对照,把每题的录音换成别种动物的(同一音色内错排,`mismatch_perm`),看模型画的是「题目的动物」还是「录音里的动物」。真在听的话,`vs_question` 应接近 0,`vs_played` 应接近正常成绩。

```bash
# 示意:接本集权重,七种题一起练,评测时加打乱对照
python sparrow.py ... --init ../weights/course_ep6/final.pt \
  --tasks t2i,t2a,t2v,i2t,a2t,v2t,a2i --steps 4000 --a2i_shuffle
```

用法上,`infer.py a2i 录音.wav 画.png` 也已经支持;但本集权重没练过 a2i,`flow_head.img` 对 a2i 序列的输出没有意义。

## 2. 看图换编码器:`--see_from img`〔本集未使用〕

[sparrow.py:85-87](../code/sparrow.py#L85)

```python
if a["see_from"] == "img":
    MODS["seelat"] = (32, 64, 1, False)
    TEMPLATES["i2t"] = ["<bos>", "<img>", ("seelat", False), "</img>", "C*", "A*", "<eos>*"]
```

i2t 改看**生成那一侧**的 FLUX.2 潜变量(64 个 32 维),同样经两层投影进入主干。比较的是「理解能不能和生成共用一套编码器」,也就是 [01](01-从输入到标签全链路.md) 第 2 节那条「理解和生成用两套编码器」的设计选择。

放到本集:

- 序列长度变成 3 + 64 + 3 = 70(原来 22)。
- `--init` 本集或第 5 集权重时,`inp.seelat`、`where.seelat` 不存在,`main` 允许它们新建初始化,并记进 `init_fresh_params`([sparrow.py:1118-1123](../code/sparrow.py#L1118))。
- `seelat` 和 `img` 读同一份缓存 `img.npz`,不用另跑 `encode.py`。两者统计量不同时,`Cache` 会分开存两份归一化数据(`img_lat` 与 `img_lat@seelat`,[sparrow.py:434-446](../code/sparrow.py#L434))。
- `infer.py i2t` 遇到这种权重会改用 `frozen.ImageVAE().encode`([infer.py:106-107](../code/infer.py#L106)),不加载 SigLIP2。

## 3. 看视频只取几帧:`--watch_frames n`〔本集未使用〕

[sparrow.py:93-95](../code/sparrow.py#L93)

```python
def watch_index(n):
    """看视频取哪几帧:16 帧均分成 n 段,各取段中点那一帧(n=1 取第 8 帧,n=16 全取)。"""
    return [(2 * k + 1) * 16 // (2 * n) for k in range(n)]
```

| n | 取的帧 | v2t 序列长度 |
|---:|---|---:|
| 1 | 8 | 3 + 4 + 4 = 11 |
| 2 | 4、12 | 15 |
| 4 | 2、6、10、14 | 23 |
| 16(本集) | 0 ~ 15 | 71 |

可以用来量「要看几帧才分得清动作」:颜色和动物看一帧就够,向左跑和向右跑要比较前后位置才分得清。`Cache` 按 `watch_index` 截取缓存里的帧([sparrow.py:384-389](../code/sparrow.py#L384)),所以不用重新编码;`infer.py v2t` 也按权重里的 `watch_frames` 取帧,并把取了哪几帧记进 `--record`(本集 `answers.json` 里的 `watch_frames` 是 0~15)。

**限制**:`configure` 会把 `MODS["watch"]` 改成 `(768, 4, n, False)`([sparrow.py:84](../code/sparrow.py#L84)),`when.watch` 的形状随之变成 `[n, 384]`。第 5、6 集权重里的 `when.watch` 是 `[16, 384]`,形状对不上,`load_state_dict` 即使 `strict=False` 也会报错;`main` 只允许 `seelat`、`vidimg` 两类部件新建。所以 `n ≠ 16` 只能从零训练,不能接本集权重。

## 4. 训练图子集:`--per_combo` / `--hold` / `--match_total`〔本集未使用〕

这三个开关决定 `Cache.img`,也就是训练时能抽到哪些图([sparrow.py:390-394](../code/sparrow.py#L390))。`Cache.get` 里 t2i 和 i2t 走同一个分支、从同一个 `self.img` 里抽([sparrow.py:460-463](../code/sparrow.py#L460)),所以:

- **它们同时影响 i2t**:`--hold red-rabbit` 不只让 t2i 没见过红兔,也让 i2t 没见过红兔的图;`see` 的统计量也只按这个子集算。
- **但 i2t 的评测不分组**:evaluate 的 4a 段仍是全部 2000 张测试图,只报总的正确率([sparrow.py:917-922](../code/sparrow.py#L917));`hold` 的专项成绩(`rep["t2i"]["hold"]`)只有画图题。想知道「没见过的组合能不能认出来」,需要另外按组合拆分 i2t 的结果,当前代码没有做。
- 视频不受影响:t2v、v2t 都从全部训练动画里抽。

## 5. 少音色训练:`--voices` / `--voice_draw` / `--clips`〔本集未使用〕

这三个开关决定 `Cache.vtr`,也就是训练录音的行([sparrow.py:397-404](../code/sparrow.py#L397))。t2a、a2t、a2i 都从同一个 `self.vtr` 里抽([sparrow.py:469](../code/sparrow.py#L469)),`hear` 的统计量也只按这些行算。所以打开后,a2t 学到的音色变少,可以量「要听过几个音色,才能听懂没听过的音色」;评测时 a2t 的 `by_voice` 能按测试音色拆开看。

## 6. 其他:批量、进度曲线、成对对照〔本集未使用〕

- **`--bs_task i2t=64,a2t=64`**:单独给某几种题设每步条数([sparrow.py:489-491](../code/sparrow.py#L489))。理解损失 100 步内就接近 0,给它们满额 512 条可能不必要;可以用这个开关量「理解题少带一些,旧题会不会忘得少」。
- **`--eval_every N` / `--eval_at 25,50,75` / `--keep_midway`**:训练中途评测([sparrow.py:580-601](../code/sparrow.py#L580))。理解题评测很快(零轮基线只用 1.2 秒),适合画「理解正确率随步数」的曲线;本集主线没开,所以只有起点(`before_training.json`)和终点两个数。
- **`--rng paired`**:每种题的抽样、时间 t、去条件、噪声各用一条独立随机流。这样「加不加理解题」两版的旧题抽样完全相同,才能把第 6 集 t2a 多错 3 条归因到理解题上(见 [04](04-理解评测推理与报告.md) 第 3 节)。协议细节见 [ep04 docs/03](../../ep04-t2a/docs/03-随机协议与可复现.md)。
